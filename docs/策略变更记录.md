# 策略变更记录

每次正式规则改动一个单独提交。回滚：`git revert <提交>` 并推送（或在线程里回复"回滚"），电脑上的自动更新一般在 15 分钟内上线并发 Telegram。

## 发布前检查（用户要求，2026-10-15，每次都必须做）

用户授权按市场效果自动优化，但每次发布前（包括进入影子并行、正式采纳、回滚、BTC 每日短线调参）必须：

1. **测试回撤**：同一数据、同一时间段，分别跑改动前和改动后，给出最大回撤（金额和占资金比例）、最长回撤持续时间、最差 5% 单笔。
2. **逐项证明更好**：改动前 vs 改动后对照表，至少包括总收益、最大回撤、胜率、盈亏比、每笔平均收益（扣手续费和滑点）、交易次数、止损次数占比，以及六种行情（普涨、山寨强于BTC、横盘震荡、山寨阴跌、暴跌、暴跌后反弹）分别的收益和回撤。必须说清好在哪里、哪里变差、为什么仍然值得改。
3. **回撤不能变差**：改动后最大回撤明显变大（超过改动前 10%）就不发布，即使收益更高。
4. **没有证明就不改**：样本不够或对照不更好，保持原规则，只记录"未发布及原因"。
5. **存档备查**：每次对照写成一份报告 `docs/策略对比记录/<日期>-<参数版本>.md`（数据来源、时间段、样本数、对照表、结论），在下表"依据"一栏链接这份报告；未发布的对照也存档，方便以后复盘。
