# 2026-10-20 BTC 每日短线方案重研（研究存档，线上规则不变）

**用户要求**：按 ATR 挂单、先挂第一单、之后跨天加仓拉低均价、至少每月盈利一次；止盈不能只拿 1%（BTC 月振幅中位数 24%）；BTC 计也要看（"涨了赚 U、跌了赚 BTC"）；以 4 年为主要口径；**绝不卖亏，只做现货，首月 10000 U**。

**结论：没有方案通过发布前检查，线上继续用现行 V2（btc-v3.2-2026-10-15-v2）。** 下面几个方案在单项指标上更好，列出来供用户决定。

原始报告：`backtest-results` 分支 `results/20261019-1842-53a6a87/report.md`。研究代码：`BtcPlanStudy`、`BtcPlanStudyMain`、`EqTracker`（`BtcV4Study` 为早期版本）。

## 方法

- 数据：data.binance.vision BTCUSDT 日线 + 15m，2020-01-01 ～ 2026-10-18。
  - 校准期（前 2/3）：2020-01 ～ 2024-06，用来选参数。
  - 验证期（后 1/3）：2024-07 ～ 2026-10，只看一次。
  - 另报滚动 4 年窗口：前三个窗口和校准期重叠，属于样本内。
- 共同规则：
  - 不止损。卖出成交价不低于含费均价 ×（1 + 手续费 + 0.3%），代码里有强制检查和单元测试，回放中出现亏损卖出会直接判为无效。实测亏损卖出 0 笔，现行 V2 也是 0 笔。
  - 加仓：上次成交价 − 间距×ATR，跨天、跨月一直有效，6 或 10 档。间距分固定 1×ATR 和递增（1、1.5、2…×ATR）两种；金额分等额和递增两种。
  - 满额后两种处理：不再买，或用本账本已实现的利润继续小额买。
- 五类方案：
  - F1：现行 V2（基线）。
  - F2：开盘 − a×ATR 挂第一单，阶梯加仓。
  - F3：近 N 日高点 − k×ATR。
  - F4：SMA50/100 上方回调到 EMA20 或 −x×ATR 时买。
  - F5：比月开盘跌 y% 时买。
- 卖法：max(0.5ATR,0.8%)；1、2、3×ATR；5%、8%、10%；回到 N 日高点；跟踪止盈（激活点 1×ATR 或 3%，回落 1 或 2×ATR 卖）。超时降目标：不降、14 天、30 天。共约 10,500 组。
- 每类在校准期选 3 个：
  - A：覆盖率不低于 F1 时年化最高；
  - B：年化大于 0 时覆盖率最高；
  - C：U 计盈利时 BTC 计增长最多。
- 基准：
  - 随机：随机日开盘买第一单，加仓和卖法相同，200 次；
  - 一直拿 USDT；
  - 期初一次全买；
  - 每月同额定投。

## 4. 结论

1. **没有方案通过发布前检查。** 要求是：比现行赚得多、覆盖率不低、五类行情不变差、优于随机，并且 U 计和 BTC 计都不差于定投和随机。线上规则不改。
2. **"月月盈利"和"赚得多"二者不可兼得。**
   - 跟踪止盈类（F2-B、F3-B、F4-B）的月度覆盖率在 4 年窗口里达到 87%～100%，验证期 81%。但每轮只赚 2%～3%，4 年 U 计只有定投的一半左右，BTC 计也更差。
   - 大止盈类（5%～10%、3×ATR）U 计明显更多，4 年窗口里两次超过定投，但覆盖率只有 30%～45%：被套的几个月里没有平仓。
3. **挂单位置没有优势。**
   - F2 系列开盘附近挂单，和随机日开盘买几乎一样（F2-C 与随机完全相同），收益来自"不卖亏 + 阶梯加仓 + 止盈幅度"，不是入场时机。
   - F4 趋势回调和 F3 深挂在验证期都不如随机。
4. **按 BTC 计，没有一个方案能稳定跑赢"期初全买"。**
   - 牛市里短线账本大部分时间拿着 USDT，BTC 计必然落后。只有大跌段 BTC 计为正，即"跌了赚 BTC"。
   - 4 年窗口里所有短线方案的 U 计都远低于期初全买。用户主仓已长期持有 BTC，短线账本的意义只能是用闲钱额外赚 U，再买 BTC。
5. **满额后用利润继续加仓**：同参数下全期 U 计约 +15%～20%，最长被套略短。小改进，可以作为任何候选的附加项。
6. **20000 / 50000 U 资金**：收益和回撤基本按比例放大，结论不变（只作参考）。

## 5. 待用户决定的两条路（都不满足发布前检查，需用户明确选择后再上线；上线时仍保留回滚到 V2）

- **路线一：保"每月盈利"**，选 F2-B，即开盘−0.1ATR 第一单、6 档加仓（间距 1×ATR、金额递增）、跟踪止盈（浮盈 3% 后从最高回落 1×ATR 卖，不低于成本 +0.4%）、14 天未卖降到成本 +0.4%。
  - 验证期和现行收益相当（+2,331 vs +2,237），覆盖率从 63% 提高到 81%，回撤更小（2,894 vs 3,950），最长被套 95 天（现行 276 天）。
  - 代价：不优于随机；4 年 U 计约为定投的一半。
- **路线二：保"赚得多"**，选 F2-C（开盘买、6 档等额、止盈 3×ATR）或 F4-C（SMA50 上回调买、止盈 10%）。
  - 4 年 U 计约为现行的 1.5～2 倍，两个 4 年窗口超过定投。
  - 代价：月度覆盖率只有约 30%～45%，最长被套约一年，验证期回撤约 6,500 U（现行 3,950 U）。
