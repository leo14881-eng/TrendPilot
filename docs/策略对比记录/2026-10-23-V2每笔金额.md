# V2 每笔金额对比（2026-10-23，只做研究，没有改线上）

## 结论

- **不发布，线上保持每笔 1,000U。** 这次是在“只买强信号”（min-buy-rel1h = 5.855，10-23 已上线测试半个月）的基础上，测试每笔金额加大。
- 加大金额后，收益确实更高，回撤也都没有超过旧规则（14,538U / 30.4%）。但跟“只买强信号 + 1,000U”这个新基准比，回撤明显变大：
  - 1,500U：U 回撤 +40%，净值回撤 11.2% → 13.4%；
  - 2,000U：U 回撤 +126%，净值回撤 11.2% → 20.5%。
  - 按发布前检查“回撤变差超 10% 不发布”的规则，所有档位都不能直接上线。
- **候选是 1,500U。** 风险调整后，它几乎和 1,000U 一样：夏普 2.56 对 2.67，卡玛 3.3 对 3.4。也就是说，多出来的收益基本是“多押钱”换来的，买入本身并没有更会挑。
  - 1,750U 的校准期反而比 1,500U 差，收益不是金额越大越好。
- 等“只买强信号”实盘影子跑满半个月（约 11-07）、确认线上表现和回测一致后，再由用户决定是否改 1,500U。
- **注意：`trendpilot.strategy.capital.trade-size` 同时决定 V1 观察账本的每笔金额。** 如果以后要改，最好先把 V2 和 V1 的金额拆成两个配置，以免 V1 对照口径跟着变。

## 方法

- 回测：GitHub Actions run 39906435762，结果在 backtest-results 分支 `results/20261023-0547-d844f66/report.md`。
- 工具：EntryStudy 新增 `cfgx_` 参数，可以一次覆盖多个线上配置项。
- 卖法：线上现行规则（ATR×1.5 止损 + 3 天等反弹 + 冻结修复）。资金池、硬顶、行情上限都不变：硬顶 20,000，RISK_OFF 时可用 60%；每笔越大，同时能持的仓越少。
- 时间：校准期 2022-10-01 ～ 2025-06-14，验证期 2025-06-15 ～ 2026-10-14。
- 随机对照：同一轮、同笔数、同金额，把币换成同币池里随机一个未持有的币。每个金额档都各配一个随机对照。
