# 2026-11-02 V6 规则用 Bybit 数据回测（V6B 的依据）

- 来源：用户只有 Bybit 账号（2026-11-02，"你决定就行，我只看结果"）。同一套 V6 规则（成交额前 150 里 24h 涨幅前 3、每笔 1,000U、退出同 V2 现行），换成 Bybit 现货数据。
- 数据来源：Bybit 公开数据站 [public.bybit.com/spot](https://public.bybit.com/spot/) 的逐笔成交（早期按月、之后按天的 csv.gz），用 `BybitArchive` 聚合成 15m K 线（taker 买入按成交方向）。Bybit v5 kline 接口在 GitHub Actions 所在地区返回 403，没有用。847 个 USDT 交易对里 681 个在区间内有数据，聚合后 1.9 GB（Actions 缓存）。没有成交的 15 分钟没有 K 线（冷门币会有缺口，缺数据不买）。
- 时段：Bybit 逐笔数据从 **2022-11** 开始，回测 **2022-12-01 ～ 2026-10-31**（前一个月做指标预热），验证期 **2025-07-02 ～ 2026-10-31**（最后 16 个月）。
- 盘口：**按 Bybit 成交额估算**的合成盘口（和 Binance 回测同一个 `Costs` 公式；Bybit 成交额更小，估算冲击更大），不是真实盘口。
- 手续费：0.1% / 边（Bybit 现货非 VIP taker 0.1%、maker 0.1%，来源：[Bybit Spot Trading: Fees Explained](https://www.bybit.com/en/help-center/article/Bybit-Spot-Fees-Explained)），和现有 `fee-rate: 0.001` 相同。
- 代币化股票 / ETF、稳定币按 R1 的同一规则排除（Bybit xStocks 在名单里）。
- 证据：Bybit [results/20261102-0321-fd89eab-bybit/report.md](https://github.com/leo14881-eng/TrendPilot/blob/backtest-results/results/20261102-0321-fd89eab-bybit/report.md)；Binance 同期 [results/20261102-0227-fd89eab/report.md](https://github.com/leo14881-eng/TrendPilot/blob/backtest-results/results/20261102-0227-fd89eab/report.md)。
