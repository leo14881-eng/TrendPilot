# 2026-10-17 V2 退出规则审查：大幅浮亏为什么没有退出

**结论先说：这是规则设计，不是执行故障。** 现行 V2 没有任何亏损退出规则（只有利润保护、上涨逻辑失效时"有净利才卖"、8% 复核、硬失效）。NXPC、CHIP、AVNT 从买入后从未进入利润保护，按规则只能"持有并观察"，所以不会卖。执行链在这三笔上基本正常，但有两处执行层面的缺口（见第 3 节）。三笔浮亏同时让系统进入 LOSS_FREEZE，形成"亏损仓不卖 → 一直冻结新买入"的死锁。

## 2. 逐项回答

**① 每笔入场时是否保存了明确的退出条件？** 没有。持仓表只有利润保护状态（protect_armed / floor / peak）、论点走弱计数、LOSS_RECOVERY 标记，没有止损价、失效位、时间限制或 1R。退出规则是全局的 ExitPolicy，不按笔记录。

**② 是否触发过退出？没触发的原因？** 没有触发任何卖出条件，原因都在规则本身：
- 利润保护：需要原始收益 ≥ 2% 且净利 > 0 才启动，三笔从未达到。
- 上涨逻辑失效（THESIS_DECAY）：三笔都满足了"连续三个小时观察走弱"，但规则是"有净利才卖，亏损时只标记 LOSS_RECOVERY 继续持有"——日志里三笔都有 LOSS_RECOVERY 事件，这就是"本该失效却不卖"的地方。
- 8% 复核：只在上涨 8% 时触发。
- 硬失效：只针对下架、黑名单、流动性严重异常，三笔都不符合。

**③ 触发后是否因冻结、缺行情、执行异常、持久化失败而没完成？** 没有"触发了没完成"的情况。但有两处执行缺口，与这三笔的亏损无关、但实盘必须补上：
- AVNT 在 10-15 有 6 轮因盘口/交易状态拿不到被跳过（电脑睡眠后网络没恢复，同时跳过的还有 WIN、GPS、MET 等 7 个币）。这几轮有记录（PARTIAL_DATA:SKIPPED=[…]）并发了 Telegram 告警，其中一条告警因服务重启没发出去（今天已修：重启后补发）。
- 10-15 18:25～21:30 UTC（越南 10-16 01:25～04:30）Monitor **整整 3 小时没有运行**（电脑睡眠，看门狗事后重启）。这段时间没有任何"无法判断"的记录，只能从 job_run 的时间缺口看出来。NXPC 就是在这段之前 8 分钟买入的。按现行规则这段时间不会卖（没进保护），但如果有止损，这就是"该卖没卖且没有留痕"。

**④ LOSS_FREEZE 是否只限制新买入和加仓？** 是。代码里只有 Discovery（V2 审核 CapitalReviewer、资金分配 CapitalAllocator）和 V1 进入读取 `newRiskAllowed`/`budgetFactor`；MonitorJob 不读风控状态。实际证据：10-16 08:17 UTC 那轮扫描被 LOSS_FREEZE 拦截，之后 09:00 UTC Monitor 仍按 THESIS_DECAY 卖出了 GPS；冻结期间持仓监控每 5 分钟照常运行（上表"系统性失败轮次 0"）。
另外，**这次 LOSS_FREEZE 正是这三笔造成的**：冻结计数 = 24 小时内亏损退出（0）+ 浮亏超过成本 5% 的持仓（NXPC、CHIP、AVNT = 3）≥ 3。亏损仓不卖，冻结就解不开。

## 3. 规则故障与执行故障的区分

| 现象 | 类型 | 说明 |
|---|---|---|
| 大幅浮亏不卖 | 规则 | 没有亏损退出；THESIS_DECAY 在亏损时只标记不卖 |
| LOSS_FREEZE 长期不解 | 规则 | 浮亏持仓永久计入冻结，和"不卖"叠加成死锁 |
| 入场没有记录失效位 / 1R | 规则 + 数据缺项 | 无法事后判断"突破是否失败" |
| 电脑睡眠时 Monitor 3 小时空窗 | 执行 | 没有"本轮无法判断"的逐笔记录；插电合盖不睡眠已在 10-16 修好 |
| 缺盘口轮次 | 执行（已处理） | 有逐笔 SKIPPED 记录、最优买价兜底、Telegram 告警；告警丢失的问题今天已修 |
| 卖出写账后没有回读校验 | 执行（缺项） | close 是事务内"删持仓 + 写 SELL 事件（event_id 唯一）"，在组合锁内按当时持仓遍历，不会重复卖；但没有写后回读核对 |

## 4. 候选退出方案：已有证据和利弊

已有回测都基于同一数据（币安现货 15m，2022-10 ～ 2026-10，每天前 150 个币，现行 V2 买入不变，手续费 0.1%×2 + 按成交额估算的冲击，收盘确认、收盘价成交）：

|---|---:|---:|---:|---:|
| 现行不止损 | +2,271 | 2,686 | 1.02% | — |
| 固定 −8%（15m 收盘） | −5,664 | 11,444 | −0.03% | 38% |

| ATR×1.5 + 3 天等反弹（冻结修复） | +20,376 | 14,538 | 0.14% | 29% |
| ATR×1.5 + 3 天等反弹（线上冻结规则） | −1,053 | 10,442 | 0.00% | 28% |

对你提的四个候选：

1. **初始止损（结构位 + ATR 检查，最大 8%，超过就不入场，仓位按 1R 计算）**
   - 利：止损在入场前就确定、只收紧不放宽，和 1R/仓位一致；超出 8% 不入场能避开波动太大的币。
   - 弊/风险：山寨日线 ATR 常在 8%～12%，ATR×1.5 平均落在约 −16%；8% 上限意味着大部分现有信号会被跳过（需要回测确认跳过比例）。固定 −8% 的结果很差（38% 被洗出），但那是"不看结构位"的版本，结构位版本**没测过**。
   - 缺项：入场时没记录突破位/有效低点，需要先从 15m K 线重建（回测可做）并在线上记录。
2. **突破失败退出（两根 15m 收盘回到突破位下方 + 相对 BTC 失效）**
   - 利：直接针对"买在假突破"，退出快、亏损小。
   - 弊：只有带"盘整突破"的信号才有明确突破位（这三笔里只有 CHIP 命中盘整突破）；其他按加速/动量入场的需要另外定义参照位。相对强势建议用现有指标：1h 相对 BTC < 0 且 4h 相对 BTC < 0（事先登记，不调）。**没测过**。
3. **时间退出（12 根完整 1h K 线没有有效上涨且相对强势消失）**
   - 利：和"3 天不赚钱等反弹"思路相同、但更快；已有证据表明"按时清理不赚钱的仓"能改善资金周转。
   - 弊：最接近的已测方案"24 小时没进保护就卖"4 年 −8,658 U，说明太早清仓会把之后的反弹全部错过。"有效上涨"需事先定义，建议：12 小时内最高可退出净利从未 ≥ 0.5R，且当前 1h、4h 相对 BTC 都 < 0。**没测过**，风险是重复"24 小时就卖"的问题。
4. **R 制盈利保护（1.5R 保本，2R 后最高净利回撤 1R 退出）**
   - 利：保护和风险挂钩，不会出现"本金 0.35% 底线"这种很小的固定值。
   - 弊：依赖第 1 条的 1R；现行保护（2% 启动、回吐本金 1% 或保留 60%）在已有数据里盈利单占绝大多数，换成 R 制后盈利单数量和金额都会变，**没测过**。

## 5. 现在不能下结论的地方（缺项）

- 结构位止损、突破失败、12 小时时间退出、R 制保护**都没有回测**，不能说有效。
- 入场时没有记录突破位、有效低点、1R，线上影子实验需要先补这些字段。
- 已有测试都显示"现行买入信号没有优势"（评分 ≥8 每年都跑输随机同档币）；离场规则只能决定亏在哪里、亏多快。任何离场方案的改善都要和同期随机基准一起看。
- 回测结果对冻结规则非常敏感（同一套止损，冻结规则不同：+20,376 U vs −1,053 U），说明结论不稳，必须做滚动样本外验证。
- 今天另一项检验：Upbit 韩元上币公告后在 Binance 买入（114 个事件，2018～2026）：延迟 1 分钟、持有 1 小时每笔 +0.91%（区间 −1.79 ～ +3.61），延迟 5 分钟起和持有 24 小时以上都是负的，**没有可用优势**。
