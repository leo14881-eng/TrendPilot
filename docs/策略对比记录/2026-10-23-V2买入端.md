# V2 买入端研究（2026-10-23）

起因：上一轮（[2026-10-23-V2盈亏不对称.md](2026-10-23-V2盈亏不对称.md)）证明只改卖法救不回来，现行规则最近 16 个月是亏的。用户同意"查买入端"，标准是"回撤数据更好，证明强于改之前的，就可以自己优化"。

- 回测入口：`com.trendpilot.backtest.EntryStudy`（GitHub Actions backtest.yml）。原始结果在 `backtest-results` 分支：
  - `results/20261023-0509-2967baf`：分组研究，现行 + 5 组随机对照
  - `results/20261023-0513-aee2992`：8 个候选过滤，每个配一个随机对照
  - `results/20261023-0518-aee2992`：相邻参数
  - `results/20261023-0524-aab5f74`：配置项实现核对
- 数据：币安现货 15m K 线，每天成交额前 150 个币，2022-10-01 ～ 2026-10-14。
- 卖法完全不变：线上现行 v3.4-2026-10-17-altstop，即 ATR×1.5 止损、3 天仍亏等反弹卖、冻结修复。买入审核、资金分配、风控都调用线上同一套类。
- 校准期 2022-10-01 ～ 2025-06-14（前 2/3），验证期 2025-06-15 ～ 2026-10-14（后 1/3）。分组切点和候选阈值只用校准期定。
- **随机对照**：现行规则决定"这一轮买几笔、每笔多少钱"，买的币换成同币池里随机一个没持有的币。卖法和风控相同。
- 置信区间：每笔均值 ±1.96×标准误。两组相减时，标准误按两组方差合并。

## 结论

**通过发布前检查**：新开仓只买 1h 相对 BTC 涨幅 ≥ 5.855 个百分点的信号。5.855 是校准期现行买入里 rel1h 的前 20% 分位。

已实现为配置项 `trendpilot.strategy.review.min-buy-rel1h`，默认 0，即不启用。加仓不受影响。正式规则上次改动是 10-17，**最早 10-31 由主线程改成 5.855 并发布**。

| 现行 vs 候选 | 现行 | 只买 rel1h ≥ 5.855 |
|---|---:|---:|
| 校准期 权益 / 最大回撤 / 每笔 | +24,366 / 6,860 / +2.29 | +27,250 / 5,036 / +3.80 |
| 验证期 权益 / 最大回撤 / 每笔 | **−3,990** / 14,310 / −0.86 | **+25,244** / 2,301 / +6.82 |
| 全期 权益 / 最大回撤 / 每笔 | +20,376 / 14,538 / +1.31 | +52,494 / 5,036 / +4.82 |
| 净值最大回撤（20,000U 资金） | 30.4% | 11.2% |
| 夏普 / 卡玛 | 1.07 / 0.6 | 2.67 / 3.4 |
| 笔数 / 平均资金占用 | 15,504 / 32% | 10,886 / 15% |

单位：权益和回撤为 U，每笔为 U。

- **每笔期望和现行比**：验证期 +7.68 ±3.12 U，全期 +3.51 ±1.65 U，都显著更好。
- **和同规则的随机对照比**：验证期 +9.83 ±3.93 U，全期 +7.00 ±1.76 U，显著优于随机。
- **相邻阈值都比现行好**（全期权益 / 最大回撤，U）：

  | rel1h 阈值 | 全期权益 | 最大回撤 |
  |---|---:|---:|
  | 4.5 | 33,726 | 9,505 |
  | 5.2 | 42,560 | 5,014 |
  | 5.855 | 52,494 | 5,036 |
  | 6.5 | 52,238 | 4,061 |
  | 7.5 | 48,367 | 4,021 |

  门槛越高，每笔越好、回撤越小，但笔数越少。阈值没有按验证期挑最好的 9，仍用校准期事先定的 5.855，以免过拟合。
- **盈亏比没有变**（0.19 → 0.20）：平均盈利 +28.7 U，平均亏损 −145.9 U，最差 5% 的交易平均 −20.1%（现行 −18.0%）。改善来自少买弱信号，不是改了"小赚大亏"的结构。
- **资金占用从 32% 降到 15%**：钱闲着的时间更多。这一项留给后面的"共用资金池"研究（实盘风控方案 2.1）。

## 买入端分解（现行规则，每笔交易的开仓特征）

先看总体：现行规则比同期随机买入每笔好多少（U）。

| 期间 | 笔数 | 胜率 | 平均盈 | 平均亏 | 每笔 ±95% | 随机每笔 ±95% | 差值 ±95% |
|---|---:|---:|---:|---:|---:|---:|---:|
| 校准期 | 10,694 | 86% | 21.55 | −115.36 | +2.29 ±1.10 | −2.27 ±0.49 | +4.56 ±1.20 |
| 验证期 | 4,810 | 84% | 22.86 | −123.79 | −0.86 ±1.84 | −3.37 ±1.86 | +2.51 ±2.62 |
| 全期 | 15,504 | 85% | 21.95 | −118.23 | +1.31 ±0.95 | −2.35 ±0.47 | +3.66 ±1.06 |

选币本身有优势：全期显著好于随机。但验证期只剩 +2.51 U，置信区间包含 0。

**按单个特征分组（26 个特征共 142 组），经多重比较校正后，没有一组在两个时期都显著**：

- 校准期用 Bonferroni 校正，z ≥ 3.57。
- 验证期要求同号，且 95% 显著。
- 完整分组表在 `scripts/backtest-entry-groups.py` 对分组研究结果目录生成的 `groups.csv`。

最一致的规律是**信号强度**：rel1h、rel4h、加速、4h 涨幅的五分位里，最强一档在两个时期都赚，最弱两档在验证期亏。

| 分组（校准期五分位） | 校准 笔数 / 每笔 | 验证 笔数 / 每笔 | 验证 合计 |
|---|---:|---:|---:|
| rel1h 最强 20%（≥5.855） | 2,139 / +6.79 | 1,196 / +8.47 | +10,127 |
| rel4h 最强 20%（≥6.689） | 2,139 / +7.68 | 1,232 / +4.89 | +6,029 |
| accel 最强 20%（≥5.874） | 2,139 / +6.64 | 1,137 / +5.93 | +6,744 |
| 4h 涨幅最高 20%（≥7.26%） | 2,134 / +7.49 | 1,142 / +5.59 | +6,388 |
| rel1h 最弱 20%（≤2.104） | 2,139 / −0.53 | 883 / −4.36 | −3,853 |
| rel1h 次弱 20% | 2,139 / +0.39 | 858 / −6.18 | −5,303 |
| rel4h 最弱 20%（≤2.242） | 2,139 / −0.19 | 922 / −5.08 | −4,688 |
| accel 最弱 20%（≤1.699） | 2,139 / +0.11 | 970 / −5.07 | −4,921 |

| 没命中"4h 强于 BTC" | 713 / −0.26 | 385 / −9.61 | −3,700 |

**其他特征没有稳定规律**：每组笔数为 1,500～2,400，校准期和验证期方向不一致，或差值置信区间包含 0。这些特征包括：

- 评分、命中项个数、盘整突破
- 距 24h/7d 高点、成交额档、币种上线时长
- 行情状态（RISK_OFF / NEUTRAL / CONSTRUCTIVE / STRONG）、六种行情
- 山寨广度（池内收在 20 日线上方比例、24h 上涨比例）
- BTC 1h/24h 走势
- UTC 时段、星期

"追高"本身没有被证明亏钱：4h、24h 涨幅越高，每笔越好。

## 候选过滤（看结果前按校准期分位登记）

每个候选都配了一个随机对照：同样的过滤，币换成随机。

| 候选 | 校准期 权益/回撤/每笔 | 验证期 权益/回撤/每笔 | 全期 权益/回撤/每笔 | 结论 |
|---|---:|---:|---:|---|
| 现行 | 24,366 / 6,860 / 2.29 | −3,990 / 14,310 / −0.86 | 20,376 / 14,538 / 1.31 | 基线 |
| F1 rel4h 前 20% | 24,196 / 4,051 / 3.38 | 19,132 / 2,534 / 5.10 | 43,328 / 4,051 / 3.97 | 通过，次优 |
| F2 rel4h 前 40% | 12,598 / 9,007 / 1.44 | 15,429 / 2,434 / 3.62 | 28,027 / 9,007 / 2.14 | 校准期变差 |

| **F4 rel1h 前 20%** | **27,250 / 5,036 / 3.80** | **25,244 / 2,301 / 6.82** | **52,494 / 5,036 / 4.82** | **通过，选用** |
| F5 剔除最弱档（rel4h、accel） | 2,201 / 12,054 / 0.28 | 2,505 / 6,794 / 0.44 | 4,706 / 12,453 / 0.33 | 变差 |

| F8 rel4h 前 30% | 12,129 / 5,490 / 1.53 | 11,731 / 4,277 / 2.89 | 23,860 / 5,490 / 1.99 | 一般 |

所有候选的随机对照全期都在 −15,000 ～ −17,000 U。

只剔除最弱档（F5）反而更差：一刀切掉弱信号后，资金会转去买中等强度的信号，而中等强度并不赚钱。**有效的是"只买最强的"。**

## 注意

- 结论只适用于测试过的方法：币安现货前 150 个币、现行卖法、本回测的成本模型。
- 验证期回测截止到 10-14，现行规则在验证期是 −3,990 U。上一轮截止到 10-21，同一数字是 −4,680 U。
- 门槛提高后笔数减少约 30%，资金占用减半。影子盘上线后，每天的买入笔数会明显少于现在。
