# 2026-10-30 BTC 主动买卖过滤 + 山寨短周期主动买入激增

起因：用户问"有没有监控 BTC 的买盘和卖盘？只看已成交的。这样对山寨币研究有没有帮助？"，之后补充"山寨可以加一个判断吗，比如实时买单是否增加，成交量大的话应该会上涨"。用户确认**不看挂单**（"挂单随时可以撤销"），只用已成交数据。

**结论先说：两部分一共 74 组可交易方案，没有一组通过发布前检查。V2、V5/V6/V7 和每周回测候选都不变。**

## 数据和方法

- 只看已成交：币安 K 线自带 taker buy quote volume（主动买入成交额），主动卖出 = 成交额 − 主动买入。数据来自 data.binance.vision 的 K 线压缩包（回测本来就在用，`Series.takerBuyQuote` 早已读入），**没有新增任何接口请求**。BTC 4h 占比缺失只有 3 个整点。
- 数据和 [10-26 H1/H2/H4](2026-10-26-H1H2H4.md) 相同：Binance 现货 15m K 线，每天成交额前 150 个币，2022-10-01 ～ 2026-10-24；校准期到 2025-06-24，**验证期 2025-06-25 ～ 2026-10-24（最后 16 个月）**。V2、V6 基准结果和 10-26 逐项相同（V2 19,343 / 14,538，V6 73,240 / 4,101），说明是同数据同时段。
- 全部方案在看结果前登记，每个方向只试 2～3 档。发布前检查用 `ReleaseCheck`（同 10-26）：验证期和全期都不低于基准、每笔期望显著更高、回撤 ≤ 基准 ×1.1、六种行情没有明显变差、显著好于同规则随机对照、**净值最大回撤 ≤ 25%**。
- 代码：`backtest.BtcFlow`（占比、30 天分位、CVD；数据缺失一律"不开"）、`BtcFlowStudy`（第一部分）、`AltFlowStudy`（第二部分）、`B0Sim.buyGate` / `pickBy`（只在回测里用，不改线上判断）。原始结果在 `backtest-results` 分支：`results/20261029-2154-1048123`（V2）、`results/20261029-2145-af9a35b`（V6 + 描述性统计）、`results/20261029-2148-1048123`（山寨短周期）。V2 第一次运行和 V6 同一分钟结束，结果目录同名被覆盖，所以 V2 重跑了一次，没有改参数。

## 第二部分：山寨自己的短周期主动买入激增 + 放量

- 迹象（8 种）：最近 **15 分钟或 60 分钟**主动买入额 ≥ 之前 24h 同长度平均的 **3 / 5 倍**，主动买入占比 ≥ **60% / 70%**，同窗口价格涨幅 **< 3%**。5 分钟级别没有测（回测数据是 15m；要测 5m 需要另外下载 150 个币的 5m 包，按这次结果看不值得）。
- 对照：只放量不看方向（成交额 ≥ 3 / 5 倍、涨幅 < 3%，4 种）；同期随机 = 每次触发的同一根 K 线，在池内随机挑一个币，同样卖法，算配对差值。
- 事件研究：每根 15m 收盘检查，同一币同一迹象 24h 只算一次，下一根开盘买，扣来回 0.1% 手续费和 1,000U 冲击。卖法：持有 1h / 4h / 24h、"+5% 后从最高回落 3% 卖（最长 24h）"。均值和 95% 区间**按天聚类**。时段用完整 4 年（数据现成），验证期单列。

- 加上"买方主导"并没有比"只放量"更好：同样窗口和倍数下，看买卖方向的每笔反而略低（例如 15m 3 倍：−0.69 vs −0.65）。验证期结论相同。

## 结论（只适用于测过的方法）

1. **BTC 的主动买卖（成交的 taker 买入占比、CVD）当山寨开仓过滤器：没有帮助。** 18 组里 17 组更差，1 组"有希望"但没通过（每笔差不显著、暴跌后反弹少 34%），只存档。描述性统计也显示 BTC 主动买入高低和之后 24h 山寨收益没有显著关系。
2. **山寨自己的短周期主动买入激增 + 放量：不能用。** 每笔都亏，不比随机好，也不比"只放量"好；当 V6 买入规则全部大幅更差。和 10-28 的结论一致：现货主动买入占比、合约主动买卖比这些"已成交"迹象，在测过的门槛和卖法下都没有优势。
3. 挂单（买单墙）按用户确认不做。
4. 目前 4 年回测里唯一稳定赚钱的仍是"已经涨起来再追"的 V6，按计划跑满 30 天（约 2026-11-25）再评估。V2、V5/V6/V7、每周回测候选都不变。
