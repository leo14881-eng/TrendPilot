- 回测的利润保护按 FastWatch 口径**正好在保护底线成交**（中位 100%）。线上 V2 也几乎正好在底线成交（101%），因为 V2 有 FastWatch（每 15 秒看 WebSocket 最优价，跌破就马上确认卖出）。
- **差距在 V2D15 和配置化变体（V5 / V6 / V7）**：它们没有 FastWatch（`FastWatch` 只看 V2 的 `ShadowBook`），只在每 5 分钟的 Monitor 检查时卖，价格已经跌过底线，卖出净利中位只有底线的 73%～83%（利润保护卖出里低于底线 98% 的：V2D15 58 / 62、V5 25 / 27、V6 26 / 27、V7 19 / 20；V2 14 / 37）。这就是 52%～57% 对 76%（复盘里的回测口径）/ 65%（本报告中位口径）的主要来源。
- 影响：回测高估了变体的平均盈利（大约少卖到底线的 20%，每笔盈利单约 −3～−5 U）。V5 / V6 / V7 满 30 天评估时应考虑这一点。是否给变体也接 FastWatch 是卖出执行的改动，需要用户决定，这里不改。
