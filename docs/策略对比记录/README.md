# 策略对比记录

每次策略发布前的改动前 / 改动后对照报告存放在这里，文件名 `<日期>-<参数版本>.md`。规则见 [策略变更记录](../策略变更记录.md) 的"发布前检查"。

每份报告包含：数据来源与时间段、样本数、对照表（总收益、最大回撤、最长回撤时间、最差 5% 单笔、胜率、盈亏比、每笔平均收益、交易次数、止损占比、六种行情分项）、好在哪里 / 哪里变差、结论（发布或不发布及原因）。
