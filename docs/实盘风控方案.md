# 实盘风控方案（真钱上线前必须完成）

2026-10-23 与用户确定。用户原话："真钱投资的时候要做好安全防范，避免大跌把之前赚的钱全部亏完""目前阶段是稳定和优化策略，做到稳定盈利"。

## 当前阶段

- **全部账本只做影子模拟。** 现阶段目标是让策略稳定、持续优化，做到稳定盈利；不接真钱。
- 真钱上线的顺序、门槛见下文；每一步都要用户明确同意。

## 一、防大跌：别让之前赚的钱一次亏回去

| # | 措施 | 状态 |
|---|---|---|
| 1.1 | 利润定期落袋：每月（或每涨一定幅度）把已实现利润的一部分（如 50%）换成 BTC 转出交易账户（冷钱包/主仓），交易账户只留本金和少量利润 | 待做 |
| 1.2 | 账户级回撤刹车：每个策略从最高点回撤 25% 停止开新仓（持仓按原规则），35% 全部暂停交易并通知用户；所有策略合计再设总上限 | 待做 |
| 1.3 | 单日暴跌：均线策略评估"盘中跌破卖出线再低 5% 提前卖出"（必须回测证明不在正常波动里被洗出）；BTC 短线不止损，靠资金上限（首月 10,000U、满额不再加仓）兜底 | 待回测 |
| 1.4 | 交易所风险：交易所只放策略要用的钱；API 只开现货交易、不开提币、绑定服务器 IP；监控 Bybit 储备证明和提币状态，异常时暂停并提醒转出 | 待做 |
| 1.5 | 程序防错：下单前检查（只允许 BTC/USDT 等许可交易对现货、金额 ≤ 对应资金、同一信号不重复下单、余额不足不下单并告警）；每天核对交易所真实余额与程序记账，差额 >1% 停止并通知；一条指令停止全部真钱交易 | 待做 |

## 二、提高资金利用率（不以增加风险为代价）

| # | 措施 | 状态 |
|---|---|---|
| 2.1 | 共用资金池：均线策略空仓时，闲置 USDT 可给 BTC 短线使用，均线策略买入时优先保证其份额；必须回测证明合并后回撤不变大 | 待回测 |
| 2.2 | 闲置 USDT 低风险理财（如交易所活期，可随时赎回）：设上限，只放必须留在交易所的部分 | 待评估 |
| 2.3 | 不做：杠杆、合约（与防大跌冲突） | — |

## 三、上线顺序

1. **硬门槛（没做完不接真钱）**：1.5 下单检查、余额核对、一键停止；1.4 API 不开提币、绑定 IP。
2. **小额实盘期间**：1.2 回撤刹车、1.1 利润定期转出。
3. **全额上线前**：回测 1.3 盘中提前卖出、2.1 共用资金池，证明有效再加。

## 四、各账本的上线前提

- **BTC 均线趋势**：对账测试、边界测试（已通过，2026-10-23）→ 14 天影子盘对比（10-23 ～ 约 11-06）→ 上面的硬门槛 → 1 份 5,000U 小额实盘 2 周 → 用户确认后全额。
- **山寨（V1/V2/V2D15/V3）**：目前没有证明比随机买入强，且盈亏不对称（止损金额远大于止盈）。先在影子盘稳定盈利、通过发布前检查和随机基准对比，才讨论实盘。
- **BTC 每日短线**：影子运行中（btc-v4-2026-10-20），按样本积累再评估。
